# Tabs 🎚️

Switch between panels with a keyboard-friendly tab bar. No dependencies.

## What it is
A minimal tabbed interface. Clicking a tab shows its panel and hides the others, with an aria-selected state for accessibility. Pure JS, no library.

## Usage
```js
tabs(container) wires up [data-tab] buttons to [data-panel] sections.
```
